# EXP 1 – Text-to-SQL Workflow

## Objective

To build an end-to-end LLM workflow with retrieval and query generation that converts natural-language questions into SQL queries and retrieves the required information from a database.

## Description

This experiment implements a Text-to-SQL workflow using Python, SQLite, Ollama, and the Llama 3.2 language model.

The system accepts a natural-language question from the user and uses the LLM to generate an SQL query. The generated query is executed on the SQLite database, and the corresponding result is displayed.

## Technologies Used

- Python
- SQLite
- Ollama
- Llama 3.2
- SQL

## Workflow

User Question  
↓  
LLM Processing  
↓  
SQL Query Generation  
↓  
SQLite Database  
↓  
Query Execution  
↓  
Result

## Result

The Text-to-SQL workflow successfully converts natural-language questions into SQL queries and retrieves the corresponding data from the SQLite database.
